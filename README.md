# 🧪 Browser Experiments

A collection of self-contained interactive simulations and generative toys. Each one is a **single HTML file** — no frameworks, no build step, no dependencies. Just open it in a browser.

**▶ Live demos:** https://hamstirr.github.io/browser-experiments/

| Experiment | What it does |
| --- | --- |
| [Gravity Sandbox](https://hamstirr.github.io/browser-experiments/gravity-sandbox.html) | N-body gravity playground — fling planets, build orbits, watch collisions. Leapfrog (symplectic) integrator so orbits stay stable. |
| [Language Evolution Engine](https://hamstirr.github.io/browser-experiments/language-evolution.html) | Seeded proto-language that splits into a family tree of daughter languages via sound changes — with grammar, writing systems and an etymology tracer. |
| [Cellular Automata Lab](https://hamstirr.github.io/browser-experiments/cellular-automata-lab.html) | Life-like cellular automata with a rule editor, presets, random rule discovery, age-based heat coloring and JSON import/export. |
| [Evolution Simulator](https://hamstirr.github.io/browser-experiments/evolution-simulator.html) | Creatures with heritable traits compete for food; watch natural selection shift the trait histograms over time. |
| [Neural Network Visualizer](https://hamstirr.github.io/browser-experiments/neural-net-visualizer.html) | A tiny neural net learning XOR in real time — forward pass, gradient flow, loss curve, switchable activations. |
| [4D Hypercube Explorer](https://hamstirr.github.io/browser-experiments/hypercube.html) | Rotate a tesseract through 4D planes with perspective, orthographic and stereographic projections, plus 3D slicing. |
| [Bistable](https://hamstirr.github.io/browser-experiments/bistable.html) | A perception instrument: ambiguous spinning figures your brain can flip between, with controls and explanations. |
| [Audioscape](https://hamstirr.github.io/browser-experiments/audio-garden.html) | A generative music garden — procedural visuals and Web Audio music that grow together. |
| [Infinite Procedural Art](https://hamstirr.github.io/browser-experiments/procedural-art.html) | Seeded generative artwork from layered noise fields, flow fields and more. Export to PNG. |

## Run locally

```bash
git clone https://github.com/hamstirr/browser-experiments
```

Then double-click any `.html` file.
